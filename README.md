# Ruogu's Word Lab

A private family learning PWA with three focused paths:

- **G1 Review Islands** — short, playful review missions across 516 Grade 1 words.
- **G2 Quiz Prep** — Cycle-based spelling practice, iPad handwriting dictation and a paper option.
- **Book Word Detective** — tricky words from books Ruogu reads on his own, sorted into "say it in chunks", "take off the tail" and "detective words". Add a new book to the end of `Book-words/book-word-data.js`.

The app shares the existing `localStorage.ruogu-literacy-profiles-v1` star total with Ruogu's literacy site. G1 and G2 learning records are stored separately under `english.g1`, `english.g2` and `english.books`.
